# 🚚 TrackSmart

TrackSmart is a project that helps users track all their online orders in one place. Instead of checking different courier websites and apps, users can view shipment updates, delivery status, and notifications through a single dashboard.

The platform also includes an AI-based prediction system that helps estimate delivery delays and expected arrival times.

## Features

- Track shipments from multiple courier partners
- View all orders in one dashboard
- Get delivery status updates and notifications
- AI-based delay and ETA prediction
- Simple analytics for shipment tracking

## Tech Stack

- React.js
- Spring Boot
- MySQL
- JWT Authentication
- REST APIs

## Why TrackSmart?

With so many online purchases being delivered by different courier services, tracking orders can become confusing. TrackSmart aims to make the process simpler by bringing everything together in one place.
